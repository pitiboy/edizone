## Quick build path

1. Source or print hopper + cone (items 1–2).  
2. Print/machining package for items 4–5, 7, 9; assemble meter module.  
3. Calibrate portions by weight; program schedule on controller (21).  
4. Mount on stand (13); route J1 harness per wiring diagram.
